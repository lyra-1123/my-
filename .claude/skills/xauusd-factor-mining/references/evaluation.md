# 评估口径与判定规则

实现：`factors/evaluate.py`。所有因子同一口径，禁止为单个因子修改。

## 数据与切分
- Dukascopy XAUUSD M1（BID，UTC），2009-01 ~ 至今；`data_loader.resample_ohlcv` 重采样到 5MIN/15MIN/30MIN/1H/4H/1D（左闭右开；日线纽约 17:00 日切）。
- 样本内 < 2020-01-01 ≤ 样本外。

## 成本与执行（用户确认，2026-09-27）
- 点差：0.2 美元 / 0.01 手（1 盎司）/ 开平一次，按 |Δpos| × 半个点差计。
- 过夜费：0.47 美元 / 0.01 手 / 每次换日，多空都收；换日时点为纽约 17:00；周三换日收 3 倍（覆盖周末），周五照常收 1 倍。
- 执行规则：≤1H 频率在 [纽约 17:00 − 2 根 K 线, 18:00) 内信号置 0，即换日前平仓、换日后 1 小时不开仓；4H/1D 持仓过夜并支付过夜费。IC 仍用原始因子计算。
- 已知残留：美国假日提前收盘的日子仓位会被带过换日（每年约 10 次）。

## 指标
| 指标 | 定义 |
|---|---|
| IC内 / IC外 | 时间序列 Spearman Rank IC，标签 = t+1 开盘 → t+1+h 开盘对数收益；主持有期 h = HORIZONS[freq] 的中间值；因子为 0 的 K 线不计入（稀疏因子） |
| 年度IC>0占比 | 全样本逐年 IC（主 h）为正的年份比例，衡量稳定性 |
| 样本外净利 | 迟滞持仓：z>1.5 做多 / z<-1.5 做空 / |z|<0.3 平仓，t+1 开盘成交，1 盎司，扣半点差×|Δpos| |
| 多头/空头毛利 | 样本外持多/持空期间的毛利，用于识别牛市 beta |
| 单笔毛利 | 毛利 / 开平次数；必须显著大于 0.2 才有实盘意义 |
| 反向净利 | 因子取负后的样本外净利（检查方向是否搞反） |
| 去漂移净利 | 样本外每根 K 线收益减去样本外平均漂移后的净利 |
| 每笔毛利ATR 内/外/近3年 | 每根 K 线收益 ÷ 上一根 ATR，**逐年去漂移**，除以开平次数；与价格水平和波动无关 |
| 年度ATR毛利>0 | 逐年的"每笔毛利ATR"为正的年份占比 |
| 当前成本ATR | (0.2 + 0.47 × 该策略平均每笔跨越的换日单位数) / 最近 1 年 ATR 中位数，即当下的成本门槛 |
| 点差/ATR | 0.2 / 中位 ATR，频率的成本门槛（5MIN≈0.20，15MIN≈0.11，30MIN≈0.08，1H≈0.05，4H≈0.03，1D≈0.01） |

## 判定（按顺序匹配）
1. **✅ 候选**：IC内>0.01 且 IC外>0.01 且 年度一致性≥0.7 且 样本外净利>0 且 去漂移净利>0 且 开平≥100 且 多头、空头毛利都>0
2. **⏳ 当前波动下可行**：每笔毛利ATR 在样本内和样本外都>0，年度ATR毛利>0 占比≥0.75，近 3 年每笔毛利ATR > 1.5×当前成本ATR，开平≥100
   （在 ✅ 之后、💸 之前匹配；不要求 IC>0，因为 IC 看的是全体 K 线，交易只发生在尾部，见 lessons L8/L11）
3. **💸 有效但成本不可行**：IC 条件同上，但样本外净利 ≤ 0
4. **🟡 观察**：IC内>0 且 IC外>0 且 净利>0 且 开平≥30
5. **🔄 方向相反**：IC内<-0.01 且 IC外<-0.01 且 年度一致性≤0.3（括号注明反向是否盈利）
6. **❌ 拒绝**：其余

"✅ 候选"只是进入下一阶段（参数平原检验、walk-forward、事件过滤、组合正交化）的门票，不等于可以实盘。

## 多重检验
库里已有几十个"因子 × 频率"组合。18 年里 ≥14 年为正，在纯随机下的概率约 1.5%；同一家族的因子高度相关，只能算一个发现。
