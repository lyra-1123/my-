# 规则适配（Rule Adaptation）

统一评估（迟滞：|z|>1.5 开仓、|z|<0.3 平仓，≤1H 换日前平仓）只用来检验因子本身。
有些因子**有稳定信息，但统一规则与它的信息结构不匹配**（信息在分布中部而不在尾部、持有期不对、需要止损等）。
规则适配就是为这类因子找到匹配的进出场规则。它本身也是参数搜索，所以要严格遵守下面的纪律。

## 1. 准入：先证明"有信息"，再谈规则
只有满足以下全部条件的"因子 × 频率"才能进入规则适配（`python -m research.icir_clusters` 输出）：
- 月度 ICIR 的 |t| ≥ 5（4H/1D 用年度 IC，因为统计功效低，原则上不进入）
- 样本内、样本外 ICIR 同号
- ICIR 为负的因子先取反（它是稳定的反向信号），并写清反向的经济逻辑

ICIR 接近 0、样本内外反号的因子**禁止**做规则适配：规则不能创造信息，只会拟合噪声。

## 2. 去重：一个簇只算一个信号
- 在样本内（2015-2019）计算候选因子值（方向统一后）的 Spearman 相关，按 |ρ| ≥ 0.6 聚类。
- 每个簇选一个代表（通常取 |t| 最大、逻辑最清楚的那个），规则只在代表上适配；簇内其他因子不再单独试规则。

## 3. 规则必须从因子的假设推出来，而不是遍历搜索
按信号类型给出有限的候选规则（每类最多 3~4 套），在样本内比较，并写明选择理由：

| 信号类型 | 信息在哪里 | 候选规则 |
|---|---|---|
| 均值回归（偏离后回归：VWAP 偏离、K 线微观结构反转、放量衰竭） | 分布中部，持有期短 | ① 固定持有期 h*（取样本内 IC 衰减曲线的峰值）② 回到参考价出场（如 z 回到 0 / 价格回到 VWAP）③ 按成本过滤：只在 ATR ≥ m×(点差+过夜费) 时交易 |
| 趋势中回调（顺大逆小） | 需要持有到趋势继续 | ① 趋势方向翻转时出场 ② ATR 移动止损 ③ 固定持有期 |
| 尾部动量（极端值延续） | 尾部，需要持有数小时 | ① 迟滞（现行）② ATR 移动止损，让利润奔跑 ③ 最长持仓时间 |
| 组合 | 多个独立簇 | 各簇代表的 z 等权平均后再套用上面对应的规则 |

规则参数（阈值、h*、m、止损倍数）只能在**样本内**选择，候选值事先列出（如 {1.0, 1.5, 2.0}），不能先看样本外再改。

## 4. 验证
- 样本外只跑一次。结果写进 `reports/rule_trials.csv`，**不论好坏都要登记**。
- 参数平原：选定参数的相邻取值，在样本内和样本外的表现都应平滑，不能是孤峰。
- 多重检验：t 值门槛随试验次数提高（Harvey-Liu-Zhu：t > 3 是最低要求）；报告结论时说明该因子一共试了多少套规则。
- 同时看：去漂移净利、夏普（策略 IR）、ATR 边际 ÷ 当前成本、逐年表现、最大回撤。

## 5. 登记格式（reports/rule_trials.csv）
`date,factor,freq,cluster,rule,params,selected_on,is_sharpe,is_net_ex_drift,oos_sharpe,oos_net_ex_drift,oos_atr_edge_ratio,n_trials_for_factor,note`
