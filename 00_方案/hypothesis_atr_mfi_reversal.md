# 假设5：ATR放大 + MFI 极值反转

（2026-09-27 用户提出。与 ATR动量v2 的区别：MFI **离开**极值区才入场（反转确认），
不要 EMA20 方向过滤，出场只用 1.5倍ATR 移动止损、不设止盈、不限持仓时间。）

## 1. 我相信

在 XAUUSD 的 M5 K 线上，MFI 处于超卖（<20）/超买（>80）区期间，如果 ATR 曾放大到基线的 x 倍以上
（x ∈ {1.5, 2, 2.5, 3}，需测试），MFI 从 20 以下反弹 / 从 80 以上回落时入场做多 / 做空，
配合 1.5 倍 ATR 移动止损，能获得正期望。

**操作定义**（2026-09-27 与用户确认）：

- **MFI**：`compute_mfi(df, 12)`，标准算法（典型价持平的bar两边都不计，本轮顺带修正）
- **ATR**：Wilder ATR(14)，**排除停盘跳空**：与上一根间隔 >180 分钟的bar，TR 只取当根 high-low
- **ATR 放大倍数**：`ATR / 前50根ATR均值`（不含当前bar）
- **做多**：`MFI[i-1] < 20` 且 `MFI[i] >= 20`（离开超卖区那一根），并且本次超卖区停留期间
  （连续 MFI<20 的那段bar）加上离开那一根里，放大倍数的最大值 >= x
- **做空**：对称，`MFI[i-1] > 80` 且 `MFI[i] <= 80`
- **不加 EMA20 过滤**
- **进场**：信号bar收盘价
- **出场**：ATR 移动止损，初始距离 1.5×入场ATR，之后按"入场以来最有利价 ∓ 1.5×入场ATR"只收紧；
  不设止盈，**不限持仓时间**；遇到 >3 小时停盘在停盘前平仓；信号bar后紧接停盘则不开仓

## 2. 因为

（用户未给出，以下为 Claude 起草，待用户确认或修改）
高波动时 MFI 进入极值区代表放量的单边资金流（恐慌抛售 / 追涨）；MFI 离开极值区说明这股资金流开始
衰竭，价格倾向于向相反方向修复。ATR 放大用来筛选"真的发生了一次剧烈单边"的情形，而不是低波动里
MFI 的正常摆动。

## 5. 失败模式

- 趋势延续：MFI 离开极值区只是单边行情中的短暂停顿，随后原方向继续（V 型反转没有发生）
- 成交量数据质量：MFI 依赖成交量，2009 年约 60% 的 bar volume=0，那段 MFI 失真
- 样本量：x=2.5/3 的信号可能太少，t 检验没有功效
- 移动止损不设止盈：反转幅度有限时，1.5ATR 的回撤距离可能吃掉大部分利润
