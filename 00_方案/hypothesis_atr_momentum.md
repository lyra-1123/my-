# 假设：ATR动量突破（EMA趋势 + 波动扩张 + MACD/RSI触发）

## 1. 我相信

在 XAUUSD 的 M5 K 线上，价格在 EMA20 上方（多头regime）/下方（空头regime），
当 ATR 放大至 1.5 倍以上时，多头regime下出现 MACD 金叉或 RSI(12) 跌破30，
或空头regime下出现 MACD 死叉或 RSI(12) 涨破70，
接下来 30 分钟内，多头方向价格至少反弹 $3、空头方向价格至少下跌 $3 的概率 > 50%。

**操作定义**（2026-09-26 与用户确认）：

- **方向regime**：`close > EMA20` → 多头regime；`close < EMA20` → 空头regime
- **ATR扩张**：`ATR(14) / rolling_mean(ATR(14), 50 根, 不含当前bar) >= 1.5`
  （ATR用Wilder平滑：`ewm(alpha=1/14, adjust=False)`；50根回溯窗口和1.5倍阈值是v1默认参数）
- **触发信号（跟方向regime配对，不允许跨方向）**：
  - 多头regime：MACD(12,26,9)金叉（`HIST[i-1]<0` 且 `HIST[i]>=0`）**或** RSI(12)跌破30
    （`RSI[i-1]>=30` 且 `RSI[i]<30`）→ 触发做多
  - 空头regime：MACD死叉（`HIST[i-1]>=0` 且 `HIST[i]<0`）**或** RSI(12)涨破70
    （`RSI[i-1]<=70` 且 `RSI[i]>70`）→ 触发做空
- **入场**：信号bar收盘价
- **反弹/下跌判定**：未来6根M5（30分钟）内，多头方向看最高价（MFE口径，`>= entry+$3`即命中），
  空头方向看最低价（`<= entry-$3`即命中），沿用之前假设的MFE口径，只是方向对称到了空头
- **RSI周期**：12（用户明确指定，不是标准14）

## 2. 因为

ATR放大到1.5倍以上，说明市场正在经历比近期平均更大幅度的波动——可能是真趋势启动或
突破，而不是盘整阴跌。这时如果价格在EMA20确立的趋势方向一侧，又出现MACD交叉或RSI
极值反转这种动量确认信号，说明趋势/反转有动能支撑，比单纯技术指标交叉（没有ATR过滤）
更可信。

## 3. 可证伪

如果回测命中率 < 50%，或者平均收益 < $5（用户原话"5块只是直觉"——注意这个阈值比
命中目标$3更高，是故意设置的更严格标准，不是笔误），放弃这个假设。

## 4. 预期效应大小

预期胜率 50-60%，逐笔 Sharpe 近似（avg_mfe/std_mfe）1.5-2.5。

## 5. 失败模式

- 假突破：ATR放大但价格没有持续，突破后立刻反转（这正是本假设最大的风险点，
  第2段的"真趋势"假设可能不成立）
