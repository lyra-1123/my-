用形态止损，能获得扣成本后的正期望。

**操作定义**（2026-09-27 与用户确认周期、入场、出场、底部容差；其余为 Claude 给出的默认值，

- **摆动低点**：`low[i]` 严格低于左边 3 根、且不高于右边 3 根的最低价；右边 3 根收盘后才算确认（因果）

  颈线 = 两底之间最高价，颈线 - 较低底 >= 1×ATR（太浅不算形态）；每个新确认的第二底配最近的合格第一底
- **入场**（**用户确认**：收盘突破颈线）：第二底确认后 30 根内，收盘价从颈线下方（含）上穿到上方

- **周期**（**用户确认**）：M5、M15、H1 各自独立识别

  - `pattern_target`：止损 = 较低底下方 0.2×ATR；止盈 = 颈线 + 形态高度（等幅测量）。
    突破K线已越过目标位的形态，此出场不适用（该笔跳过）

## 2. 因为

（用户未给出，以下为 Claude 起草，待用户确认或修改）
双底表示同一价位的支撑被测试两次都守住，卖方力量在这一价位耗尽；收盘突破颈线说明两底之间的
反弹高点（上方的卖盘）也被吸收，买方接手。这是最广为人知的形态之一，大量交易者盯着同一条颈线，
突破时的集中下单可能带来自我实现的延续。

- 规则化的"双底"与肉眼看到的双底不一致：请用脚本打印的样例在 MT5 图上抽查，

**诊断**：

1. **M5/M15：方向边际显著为负**（t 最低 -4.87；即使按累计 36 次试验做 Bonferroni 校正，
   |t|>3.2 仍显著）。这是本项目第一个统计上真实的方向效应：**收盘突破颈线之后，价格略倾向于
   回落，突破方向比随机方向更差**。持仓最短的 trail 出场最显著，符合短周期"突破K线收在极端位置
   之后的微观回吐"。但幅度只有 0.01-0.03R，反向做（镜像同样距离）成本前约 +0.01~+0.04R，
   仍低于成本（M5 0.126R、M15 0.069R），**统计显著但经济上不可交易**。
2. **H1：无方向效应**（|t| <= 1.22）。双底做多边际 +0.02~+0.05R、双顶做空 -0.00~-0.05R，
   多空不对称来自 2009-2026 黄金从约 $900 涨到约 $4300 的长期漂移（单方向子集的"边际"
   包含漂移，多空合计时相互抵消），不是形态本身的能力——"只做双底"不是改进方向。
3. H1 按年份：边际正负交替，只有 2015 年 t=2.17（18 年里出现 1 次属随机预期）。
4. H1 的 GAP 出场占比高（2R 出场 861/2467 = 35%），因为周末前强制平仓；两个方向用同一规则，
   对方向边际的比较是公平的，但会改变收益形态。
5. 形态数量偏多（M5 每天约 5 个）：1×ATR 颈线深度在 M5 上门槛很低，规则化的形态包含大量
   肉眼不会认作双底的小结构。三个周期结论一致，不影响"没有正向边际"的结论。

**结论**：REJECTED，不进第5章。
