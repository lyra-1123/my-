# 假设：MACD 水下金叉反弹

## 1. 我相信

在 XAUUSD 的 M5 K 线形成"水下金叉"且"快慢线离绿柱较远"时，
在接下来 30 分钟内至少会反弹 $10 的概率 > 70%。

**操作定义**（2026-09-26 与用户确认，signal_macd_underwater_cross.py 必须严格照此实现）：

- MACD 参数：12 / 26 / 9（标准），基于 M5 收盘价，`DIF = EMA12 - EMA26`，`DEA = EMA(DIF, 9)`，
  `HIST = DIF - DEA`
- **水下金叉**：某根 K 线 `i` 满足 `HIST[i-1] < 0` 且 `HIST[i] >= 0`（金叉confirm在i），
  同时交叉前一根 `HIST[i-1]` 对应的 `DIF[i-1] < 0` 且 `DEA[i-1] < 0`（两线交叉前都在0轴下方）
- **快慢线离绿柱较远**：交叉前一根柱值 `HIST[i-1]`（负值），比 `NARROWING_LOOKBACK=5` 根之前的
  `HIST[i-1-5]` 更接近 0（即已经走窄），`NARROWING_LOOKBACK` 是 v1 默认参数，后续在参数搜索阶段调整
- **反弹判定（用于验证，不是信号本身的一部分）**：信号确认K线 `i` 收盘价为入场价，
  未来 6 根 M5 K线（30分钟）内的最高价 - 入场价 ≥ $10 即算命中（MFE 口径，只要盘中触及即可，
  不要求收盘价还站在高位）

## 2. 因为

水下金叉发生时市场经历了一段下跌（DIF/DEA都在0轴下方），且下跌动能（绿柱）已经在走窄，
说明卖压逐渐被消耗；此时快线上穿慢线，是动能由弱转强的信号，做市商/短线资金倾向于在此时
入场做多制造反弹。

## 3. 可证伪

如果回测命中率 < 50%，或者平均收益（MFE）< $5，放弃这个假设。
