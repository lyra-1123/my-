# 假设：多周期金叉共振反弹

（假设1 `hypothesis_macd_underwater_cross.md` 已 REJECTED，这是同一方向下的第二次尝试，
改用多周期共振代替单一M5信号。）

## 1. 我相信

在 XAUUSD 的 1H K线形成"水下金叉"后，30min / 15min / 5min 也形成金叉，
在 5min 级别金叉confirm的那根K线入场，接下来 30 分钟内至少会反弹 $10 的概率 > 70%。

**操作定义**（2026-09-26 与用户确认）：

- MACD 参数：所有周期统一用 12/26/9
- **1H 水下金叉**：某根 1H K线 `i` 满足 `HIST[i-1]<0` 且 `HIST[i]>=0`，且 `DIF[i-1]<0` 且
  `DEA[i-1]<0`（水下），且 `HIST[i-1]` 比 `NARROWING_LOOKBACK_1H=5` 根1H之前的 `HIST` 更接近0
  （走窄，沿用假设1的定义）
- **30min / 15min 金叉**：不要求水下、不要求走窄，只要求"当前处于金叉后状态"
  （即 `HIST>=0`，从最近一次金叉到现在没有再死叉）
- **有效期窗口**（统一按"过去3小时"换算成各周期bar数，避免旧金叉还在算数）：
  - 1H：金叉后状态必须在最近 **3 根**1H内触发（即3小时内），且期间未死叉
  - 30min：金叉后状态必须在最近 **6 根**30min内触发，且期间未死叉
  - 15min：金叉后状态必须在最近 **12 根**15min内触发，且期间未死叉
- **入场触发（5min）**：5min K线本身刚发生金叉confirm（`HIST[i-1]<0` 且 `HIST[i]>=0`，
  不要求水下/走窄），且此刻对齐的 1H/30min/15min 都仍处于各自"金叉后有效期内"的状态
- **时间顺序**：不要求 1H→30min→15min→5min 严格按顺序发生，只要求 5min 入场那一刻，
  三个更高周期"当前状态"都满足即可
- **对齐方式（严格因果，禁止未来函数）**：某个5min时刻能用的1H/30min/15min数据，
  必须是**已经完全走完**的那根K线（比如14:23这根5min，只能用13:00-14:00那根已收盘的
  1H K线，不能用14:00-15:00那根还没走完的）——用 confirm_time = bar起始时间 + 周期长度，
  按 confirm_time <= 当前5min时刻 取最近一条
- **反弹判定**：入场价 = 5min信号confirm那根K线收盘价；未来6根5min（30分钟）内最高价，
  相对入场价涨幅 >= $10 即算命中（沿用假设1的MFE口径）

## 2. 因为

单一周期的金叉噪音大（假设1已验证：IC全程接近0）。多周期共振的逻辑是：1H的水下金叉代表
大级别超卖动能已经转向、且走窄说明卖压在衰竭；30min/15min的金叉代表中级别趋势也开始跟随；
5min金叉是精确的入场时机。三级别同时确认，理论上能过滤掉大部分"局部噪音金叉"，只留下
真正的多级别趋势拐点。

## 3. 可证伪

如果回测命中率 < 50%，或者平均收益（MFE）< $5，放弃这个假设。

## 4. 预期效应大小

预期胜率 50-60%，逐笔 Sharpe 近似（avg_mfe/std_mfe）1.5-2.5。

## 5. 失败模式

- 单边下跌市场（多周期"金叉"本身在强趋势下可能只是死猫跳，continuation而非反转）
- 信号本来就稀疏（多重条件叠加，触发次数可能很少，统计显著性不足——验证时需要先看
  n_signals 是否够多，太少的话三件套的结论不可靠）
- （后续验证中发现的其他失败场景，补充在这里）

**2026-09-26，全量真实数据（XAUUSD M1 2008-12-31~2026-09-25，重采样M5共128万根）**

```
信号次数: 200
命中率 (未来30分钟MFE>=$10): 3.5%
平均 MFE: $2.30 (std $3.03)
平均 MAE: $-1.93
逐笔 Sharpe 近似: 0.76

对照组（不看信号、随便一根bar的基线）: 命中率 1.9%，平均MFE $1.77
增益: +1.6 个百分点（信号命中率约是基线的 1.8 倍）

IC稳定性: 18年里只有1个滚动窗口凑够统计所需的最小信号数(>=5)，IC=-0.0077，
样本太少，无法判断稳定性。
```

**结论：❌ 按可证伪标准（命中率<50% 或 平均MFE<$5 应放弃）仍然 REJECTED。**

但和假设1（完全零边际，2.0% vs 基线1.9%）不同，这次信号命中率是基线的约1.8倍，
说明"1H水下金叉+多周期共振"这个机制本身不是纯噪音，确实过滤掉了一部分低质量的单一
周期金叉。问题是：
1. 强度远不够——$10/30分钟这个目标对这个机制来说定得太高，实际能过滤出的边际效应
   只有平均MFE $2.30 这个量级
2. 样本太薄——200次信号/18年（约11次/年），IC稳定性检验基本没法跑，1.6个百分点的
   提升本身的统计显著性存疑

**状态：REJECTED（对原定目标），但机制本身可能值得未来复用**——如果以后有新假设
用到"多周期共振过滤"这个思路，可以参考本假设的 `signal_mtf_golden_cross_cascade.py`
代码框架，但反弹目标应该定得更保守（比如 $3-5 而不是 $10），且需要放宽某个周期的
有效期窗口以增加信号数量到能做可靠IC检验的量级。
