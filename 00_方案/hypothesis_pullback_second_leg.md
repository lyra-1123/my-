# 假设9：趋势回调 50% 入场，等第二段（ABC 等幅）

（2026-09-27 用户提出，回到价格行为方向。）

## 1. 我相信

多头趋势中，第一段上涨 A→B 之后回调到 50% 挂限价做多，止损放在起涨点 A，止盈为第二段上涨高度 =
第一段高度（成交价 + (B−A)），能获得扣成本后的正期望。空头对称。

**操作定义**（2026-09-27 与用户确认：第一段门槛 2/3/5×ATR、大周期同向过滤、限价单碰到即成交、
M5 与 M15；其余为 Claude 默认值，见 `04_策略研究/signal_pullback_second_leg.py`）：

- A：已确认的摆动低点（左右各 3 根，右侧 3 根收盘后确认）
- B：A 之后到上一根为止的最高价，出现新高就上移（因果，不用未来的高点）
- 挂单条件（全部满足时在 L=(A+B)/2 挂买入限价）：B−A >= 门槛×ATR；大一级周期（M5 看 M15、M15 看 H1）
  最近一根已收盘K线收盘价在 EMA50 上方；B 出现之后价格还没碰过 L
- 成交：最低价 <= L，按 min(L, 开盘价) 成交；开盘已低于 A 则不成交
- 撤单：跌破 A，或 A 之后 100 根仍未成交；每个 A 最多一笔
- 止损：A（按用户描述不加缓冲）；止盈：成交价 + (B−A)，50% 处成交时盈亏比 1:2；不限持仓，遇 >3 小时停盘平仓
- 成交当根：成交后的剩余走势按 [当根最低, max(成交价, 收盘)] 近似，先判止损；随机方向对照用同一近似
- 成本：$0.30/笔

## 5. 失败模式

- 回调不止 50%：趋势已结束（V 型反转或区间震荡），止损在 A 被打到
- 止损正好在摆动低点上，常被插针扫掉（未加缓冲）
- 第一段门槛 2×ATR 太小，混入大量噪音"趋势"
- 大周期 EMA50 过滤在震荡市里频繁翻转

   而不是与随机方向比较。按年份边际正负交替。
4. **隔夜利息未计入**：平均持仓 5.6-29 晚，H4 以 $0.5/盎司/晚 粗估，20 晚约 $10 ≈ 0.36R，足以吃掉 H4 的全部成本后R。

   **回调延续是短周期日内现象，量级低于零售成本；高周期上只剩漂移。**

**结论**：假设9（v1 / v2 / v2b 共 14 个组合）REJECTED。
