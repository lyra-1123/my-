# 假设：单一大周期金叉 + 5min入场（反弹目标降为$5）

（假设1、假设2都已 REJECTED。假设2的多周期共振显示出约1.8倍基线的真实增益，
但强度不够、样本太薄。这版简化掉"三周期同时满足"的强约束，只保留一个大周期，
换取更多信号样本，同时把反弹目标从$10降到$5，看能不能找到一个可行的组合。）

## 1. 我相信

在 XAUUSD 的某个大周期（1H 或 30min 或 15min，三选一）形成水下金叉（+走窄）后，
在 5min 周期金叉confirm那一刻入场，接下来 30 分钟内至少反弹 $5 的概率明显高于基线。

**操作定义**（沿用假设1/2已确认的定义，只改两处：单一大周期、目标金额）：

- 大周期候选：1H / 30min / 15min，三个都跑一遍对比，不预设哪个更好
- 大周期条件：**水下金叉 + 走窄**（复用假设2给1H用的定义：交叉前 `DIF<0` 且 `DEA<0`，
  且交叉前一根柱值比 `NARROWING_LOOKBACK=5` 根之前更接近0），不管选哪个大周期都用这套定义，
  这样三个候选之间是公平对比（只是时间尺度不同，机制定义一致）
- 有效期窗口（沿用"3小时等效根数"）：1H=3根，30min=6根，15min=12根
- 入场：5min 金叉confirm那一刻，且此刻对齐的大周期仍在有效期内（因果对齐方式不变，
  用 confirm_time = 大周期bar起始 + 周期长度）
- **反弹目标从 $10 降到 $5**：未来6根5min（30分钟）内最高价 - 入场价 >= $5 即算命中
- 其余（MACD参数12/26/9、MFE口径、30分钟窗口）不变

## 2. 因为

假设2已经验证"多周期共振"这个方向有真实但偏弱的效应（3.5% vs 1.9%基线）。
可能是三层同时满足的约束太强，把样本量压缩到200次导致既筛不出稳定性、
也筛不出更高的绝对命中率。去掉两层约束、只留一层，样本量应该显著增加，
同时降低目标金额到与假设2实测的平均MFE（$2.30）更接近的量级，看看命中率和
稳定性能不能达到可用标准。

## 3. 可证伪

如果三个大周期选项里最好的那个，命中率仍然 < 50%，或平均MFE < $3（原$5的一半，
因为目标本身已经降到$5，成功标准也相应下调），放弃整个"金叉反弹"方向，
换用完全不同的假设类型（不再是MACD金叉类）。

## 4. 预期效应大小

不预设具体数字——这次是探索性质，先看三个大周期选项谁的命中率相对基线的提升
（lift）最大、且信号数量是否够多能撑起可靠的IC检验（至少几百次触发）。

## 5. 失败模式

- 单边下跌市场
- 如果三个大周期选项的lift都和假设2类似（~1.8倍基线但绝对值仍然很低），
  说明"金叉+方向对齐"这个机制上限就在这里，该换方向了
