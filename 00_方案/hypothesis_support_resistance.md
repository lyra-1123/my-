# 假设7：支撑 / 阻力（价格行为）

（2026-09-27 用户提出：在价格行为形态上增加支撑位/阻力位。）

## 1. 我相信

在 XAUUSD 的 M5 / M15 / H1 上，(a) 落在事先已存在的支撑/阻力位上的双底/双顶比普通双底/双顶更可靠；
(b) 价格触及支撑/阻力后收回，会从该价位反弹/回落。两者扣成本后都有正期望。

**操作定义**（2026-09-27 与用户确认：4 种识别方法、2 种用法、3 个周期；其余为 Claude 默认值，
见 `lib/goldq/levels.py` 与 `04_策略研究/signal_support_resistance.py` 顶部常量）：

- **价位识别**（不分支撑阻力，价格下方为支撑、上方为阻力；全部只用当时已知的数据）：
  - 多次触及：最近 200 根内 >= 3 个已确认摆动高/低点聚在 0.5×ATR 以内，取均值；存活 200 根，保留最近 10 个
  - 大周期高低点：M5/M15 用 H4、H1 用交易日；最近 5 个摆动高点 + 5 个摆动低点
  - 前日/前周：前一交易日高/低/收 + 前一交易周高/低；交易日以纽约 17:00 为界
  - 整数关口：$50 的整数倍（上一根收盘价上下各两个）
- **过滤双顶双底**：双顶双底定义同假设6；较低底（双顶为较高顶）与某个价位相差 <= 0.5×ATR，
  且该价位在第一个底/顶出现前已知
- **触及反弹**：最低价 <= 支撑 + 0.1×ATR、收盘 > 支撑、前一根收盘 > 支撑 → 做多；阻力对称做空；
  同方向 6 根内不重复
- **出场**：统一为给定止损 + 2R 止盈，不限持仓，遇 >3 小时停盘平仓。
  过滤用法止损 = 形态止损（较低底下方 0.2×ATR）；反弹用法止损 = min(当根最低, 价位) 下方 0.2×ATR
- **成本**：$0.30/笔
