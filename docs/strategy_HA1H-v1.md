# 策略说明书：HA1H-v1（XAUUSD 1 小时 · 52 周高点锚定动量）

> 状态：**模拟盘前向测试中**（2026-09-28 起），行为指纹 `c1ca467d69ce1ed7`。影子版本 `HA1H-TS2-shadow`（按状态回补 + 2×日 ATR 移动止损，指纹 `2cf943680e1b318e`）同时运行，只用于与 v1 做前向对比。代码：`paper/specs.py`（规格）、`factors/library/trend_continuation.py::factor_high_anchor_momentum`、`factors/core.py`、`factors/evaluate.py`、`paper/engine.py`。
> 研究记录：`reports/trend_continuation_batch8.md`、`reports/batch8_candidate_validation.txt`。

## 1. 一句话概括
当金价处在过去一年（250 个交易日）价格区间的**极端位置**（相对最近约 6 周的常态明显偏高或偏低）时，顺着这个方向持有；每天纽约 16:00 平仓、19:00 起按同样规则重新入场。

## 2. 交易逻辑
- **锚定效应**（George & Hwang 2004）：投资者会把"一年内的最高价/最低价"当作参照点。价格接近或突破一年高点时，大家觉得"已经很贵了"，买入不足，价格对利好消息反应偏慢；突破之后，这种反应不足逐步被纠正，价格继续上行。接近一年低点时对称。
- 黄金在 2009-2026 年的长期上涨中频繁创出一年新高（2011、2020、2024-2026 年），锚定效应的机会多。
- 与 TT30 的区别：TT30 看的是 30 分钟**价格路径**的极端（数小时级别的冲击），HA1H 看的是**日线级状态**（价格在一年区间中的位置，数日到数周级别），两者的触发时点不同，日度收益相关只有 0.17。

## 3. 数据
与 TT30 相同：Dukascopy M1（BID，UTC，含成交量），重采样为 1 小时 K 线（`[t, t+1h)` 左闭右开），丢弃未走完的 K 线。
另需**日线**：由同一份数据按 UTC 自然日重采样；只使用**已收盘**的日线（当天的日线在当天结束前不可用）。

## 4. 信号计算
参数（先验值，未调参）：`anchor_days = 250`，`norm = 1000`（1 小时 K 线，约 43 个交易日）。
```
H250 = 已收盘日线最近 250 日的最高价（至少 200 日）
L250 = 已收盘日线最近 250 日的最低价
pos  = 2 × (C − L250) / (H250 − L250) − 1        # C 为当前 1H 收盘价；区间底部 −1，顶部 +1，突破新高 > 1
z    = MAD_Z( clip(pos, −3, 3), 1000 )          # 滚动 1000 根 1H K 线去极值 + 标准化
```
- MAD_Z 与 TT30 相同：滚动中位数 ± 3×1.4826×MAD 截断，再做滚动均值/标准差标准化（最少 250 个样本）。
- 含义：z 衡量"价格在一年区间中的位置，相对最近约 6 周的常态有多极端"。z > 0 看多，z < 0 看空。

## 5. 交易规则（与 TT30 完全相同的统一执行规则）
- **执行时间窗（纽约时间，自动处理夏令时）**：1H 频率下，15:00、16:00、17:00 三根 K 线的 z 视为 0 →
  **16:00 开盘平掉所有仓位**，换日（17:00）时一定空仓；**最早 19:00 开盘重新入场**。
- **迟滞开平仓**（每根 1H K 线收盘后判断）：z > 1.5 做多；z < −1.5 做空；|z| < 0.3 平仓；持仓中出现反向极端信号直接反手；其余情况维持。
- **成交**：第 t 根收盘出信号，第 t+1 根开盘市价成交；固定 **0.01 手（1 盎司）**；无止损、止盈、最长持仓时间。

### 5.1 规则的实际效果（重要）
因子是"在一年区间中的位置"，一天之内几乎不变，因此：
- **98% 的交易（1941/1987）由"16:00 换日前平仓"结束**，只有 46 笔由信号消退或反手结束（这 46 笔合计 −1183$）。
- **2/3 的入场发生在纽约 19:00**，即换日后第一根允许入场的 K 线；**82.5% 的交易是"与前一交易日同方向的隔日重新入场"**。
- 所以它本质上是一个**多日持仓的趋势策略**，只是每天在 16:00–19:00（纽约）被拆开：
  - 合并隔日重入后，共 **347 个"持仓段"**，平均持续 **5.7 个交易日**（中位 4 天，最长 41 天），段胜率 43%，平均盈利 +35.6$ / 平均亏损 −17.5$（盈亏比约 2:1）。
  - 每天平仓再开仓要付一次点差 0.2$，但**比持仓过夜付过夜费 0.47$ 更便宜**（周三更是 1.41$），所以每日拆分反而节省成本。
- 在场时间约 33%（做多 16%、做空 17%）。

## 8. 风险与限制
1. **统计证据弱**：自身 DSR 只有 0.28，定位为组合中的分散化成员，不宜单独使用。
2. **每日 19:00（纽约）入场的执行风险**：2/3 的入场发生在换日后第一个小时结束时（亚洲早盘），此时实际点差可能仍高于 0.2$。实盘前应核实该时段的真实点差；如果明显更宽，需要把入场推迟（这属于规则变更，要另立版本并重新检验）。
3. **趋势跟踪画像**：持仓段胜率 43%，依赖少数大盈利；2025-2026 年的高波动贡献了大部分美元利润。
4. **与 TT30 同样的限制**：没有止损（风控放在组合层面熔断）；使用成交量以外的数据只有 OHLC，但日线区间依赖 UTC 日切。
