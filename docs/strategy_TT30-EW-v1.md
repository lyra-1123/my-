# 策略说明书：TT30-EW-v1（XAUUSD 30 分钟趋势尾部 · 等权组合）

> 状态：**模拟盘前向测试中**（2026-09-28 起），行为指纹 `2a082351a3ab07bf`（2024 年全年的信号与目标仓位哈希）。
> 代码实现：`paper/specs.py`（规格）、`factors/library/trend.py`（两个因子）、`factors/core.py`（公共函数）、`factors/evaluate.py`（执行规则与成本）、`paper/engine.py`（模拟盘引擎）。
> 本文档是后续**实时下单程序**的实现依据；实时程序必须与 `paper/engine.py` 逐 K 线一致（见第 8 节）。

---

## 1. 一句话概括

在 XAUUSD 30 分钟 K 线上，当"趋势效率 × 放量"和"价格相对 VWAP 的偏离"这两个趋势信号的等权组合达到**极端值**（|z| > 1.5）时顺势开仓；信号消退（|z| < 0.3）时平仓；每天纽约 17:00 换日前强制平仓。

## 2. 交易逻辑

| 观察 | 证据 |
|---|---|
| 黄金在日内**温和**的偏离/趋势之后倾向**反转**（≤15 分钟最明显） | 5MIN 上 5 个动量类因子 2009-2026 每一年 IC 都为负 |
| 但**极端**的趋势信号会**延续**，而且需要持有数小时 | 30MIN 趋势因子全体 K 线 IC 为负，而只在 \|z\|>1.5 时交易、持仓约 10 小时，逐年盈利 |

- 解释：极端的单边位移代表真实的新信息或大资金进场，趋势跟随资金与止损盘推动行情延续（尾部动量）；温和的波动则主要是流动性噪声，会被均值回归吃掉。
- 因此本策略**只在尾部交易、持有到信号消退**，而不是跟随每一次小波动。

## 3. 数据

| 项目 | 规格 |
|---|---|
| 品种 | XAUUSD |
| 数据源（研究与模拟盘） | Dukascopy M1，**BID 价**，**UTC 时间**，含 Dukascopy 成交量 |
| 字段 | open / high / low / close / volume，不使用任何其他字段 |
| 30 分钟 K 线 | 由 M1 重采样：`[t, t+30min)` 左闭右开，标签为左端时间；open=首根 open，high=max，low=min，close=末根 close，volume=求和 |
| 未走完的 K 线 | 丢弃：只使用 `开始时间 + 30min ≤ 最后一根 M1 时间 + 1min` 的 K 线 |
| 无成交 K 线 | M1 中 volume = 0 的行在重采样前剔除 |

## 4. 信号计算（以 30MIN 为准，所有窗口单位为"根 30 分钟 K 线"）

参数（均为入库时的先验值，未调参）：`chan = 32`，`atr = 32`，`vol_base = 20`，`norm = 1000`。

### 4.1 公共函数
- **ATR(n)**：TR = max(H−L, |H−C₋₁|, |L−C₋₁|)，Wilder 平滑 `EWM(alpha=1/n, adjust=False, min_periods=n)`。
- **相对成交量 RelVol**：当前 volume ÷ "过去 20 个交易日**同一时刻**（UTC 时:分）的 volume 中位数"（不含当前这一根；最少 5 个样本）。用于消除亚盘/伦敦/纽约的成交量季节性。
- **MAD_Z(x, w=1000)**（滚动去极值 + 标准化，最少 250 个样本）：
  1. med = 滚动中位数(x, w)；MAD = 滚动中位数(|x − med|, w)
  2. 截断到 med ± 3 × 1.4826 × MAD（MAD = 0 时不截断）
  3. z = (截断值 − 滚动均值) / 滚动标准差（标准差为 0 时 z = 0）

### 4.2 因子 A：放量趋势效率 TrendEfficiencyVolume
```
ER       = (C − C₋₃₂) / Σ₃₂|ΔC|                 # 有方向的效率比 ∈ [−1, 1]
VolTrend = max( mean₃₂( ln RelVol ), 0 )        # 近 32 根平均放量程度，只取放量部分
A        = MAD_Z( ER × (1 + VolTrend), 1000 )
```

### 4.3 因子 B：滚动 VWAP 偏离 VWAPDeviation
```
TP   = (H + L + C) / 3
VWAP = Σ₆₄(TP × V) / Σ₆₄(V)                     # n = 2 × chan = 64 根
B    = MAD_Z( (C − VWAP) / ATR(32), 1000 )
```

### 4.4 组合信号
```
z = MAD_Z( 0.5 × A + 0.5 × B, 1000 )            # A、B 的缺失值按 0 处理
```
z > 0 看多，z < 0 看空。

## 5. 交易规则

### 5.1 执行层时间窗（纽约时间，自动处理夏令时）
- 在 **[16:00, 18:00)**（纽约）内的 30 分钟 K 线，z 强制视为 0。
  - 效果：**16:30 开盘时平掉所有仓位**（16:00 那根 K 线收盘后发出平仓信号），换日（17:00）时一定空仓，**不付过夜费**；
  - 换日后第一个小时（点差最宽）不开新仓，最早 **18:30** 开盘可以入场。

### 5.2 迟滞开平仓（每根 30 分钟 K 线收盘后判断）
| 条件 | 空仓 | 持多 | 持空 |
|---|---|---|---|
| z > 1.5 | 开多 | 持有 | 反手做多 |
| 0.3 ≤ z ≤ 1.5 | — | 持有 | 持有 |
| \|z\| < 0.3 | — | 平仓 | 平仓 |
| −1.5 ≤ z ≤ −0.3 | — | 持有 | 持有 |
| z < −1.5 | 开空 | 反手做空 | 持有 |

### 5.3 成交
- 信号在第 t 根 K 线**收盘**时确定，在第 t+1 根 K 线**开盘**以市价成交。
- 仓位：固定 **0.01 手（1 盎司）**，只有多 / 空 / 空仓三种状态；不加仓、不减仓。
- **没有止损、止盈、最长持仓时间**：出场完全由信号消退或换日前平仓触发。

## 6. 成本假设
- 点差：0.2 美元 / 0.01 手 / 开平一次（回测按每单位仓位变化收半个点差）。
- 过夜费：0.47 美元 / 0.01 手 / 每次换日，多空都收，周三 3 倍。本策略换日前平仓，正常情况下不付过夜费；美国假日提前收盘的日子（每年约 10 次）平仓窗口内没有 K 线，仓位会被带过换日。
- 没有模拟滑点。回测只用 BID 价，点差按固定值扣除。

## 8. 主要风险与限制
1. **依赖高波动环境**：点差是固定美元，2009-2019 年（金价 1100~1800、ATR 小）按美元只是保本，点差 ×1.5 即转负。盈利主要来自 2020 年后波动放大；如果波动回落，策略会退回保本。
2. **选择偏差**："30 分钟趋势"是在研究过程中挑出来的；DSR 只有 0.69，最终只能靠前向测试确认。
3. **典型的趋势跟踪画像**：胜率约 40%，依赖少数大盈利，会出现较长的连续亏损（回测年内最大回撤 −40 ~ −402 美元 / 0.01 手）。
4. **没有止损**：极端行情中单笔亏损只受信号反转速度限制。
5. **数据源依赖**：信号使用了成交量。Dukascopy 的成交量与经纪商的 tick volume 不同；换数据源会改变信号（见第 9 节）。

## 9. 实时下单程序的实现要求（后续开发）

### 9.1 必须满足
- **与引擎逐 K 线一致**：在一段重叠的历史上（至少 3 个月），实时程序算出的 z 与 `paper/engine.py` 相差 < 1e-6，目标仓位完全相同；上线前和每次改代码后都要对账。
- **预热数据**：两层 MAD_Z（窗口 1000）、RelVol（20 个交易日）、ATR 的 EWM 都依赖历史。每次计算至少提供 **6000 根 30 分钟 K 线（约 6 个月）**，最稳妥的做法是和引擎一样用全部历史重算。
- **时间与时区**：统一使用 UTC 构造 30 分钟 K 线；MT5 等平台的服务器时间（常见 GMT+2/+3，随夏令时变化）必须先换算成 UTC。执行时间窗按纽约时间判断。
- **只用已收盘的 K 线**：每根 30 分钟 K 线收盘后（UTC :00 / :30）重新计算，在下一根开盘时下单。
- **状态以"目标仓位"为准**：每次都由全部历史重算出目标仓位，再与账户实际持仓比较并下单补齐（幂等），不要依赖程序内部累计的状态。重启、断线后自动恢复到正确仓位。
- **数据源一致性**：优先直接使用 Dukascopy 实时数据（与研究同源）。如果改用经纪商数据（MT5 的 bid 与 tick volume），必须先在重叠历史上比较两者的 z 与目标仓位，一致率不够就不能直接替换。

### 9.2 建议具备
- 下单前检查：点差是否异常（例如 > 0.5 美元时延迟下单并告警）、仓位是否与目标一致、数据是否过期（最新 K 线距今超过 35 分钟就停止开新仓）。
- 记录：每次计算的 z、目标仓位、实际成交价与时间，写入 `paper/state/TT30-EW-v1/fills_manual.csv` 的同格式日志，用于滑点统计（`python -m paper.report` 会自动计算）。
- 熔断：前向累计 R 跌破登记的 5% 分位（见第 10 节）时自动停止开新仓，并通知人工复查。

## 10. 前向测试评估标准（登记时写死，见 `paper/state/TT30-EW-v1/prereg.json`）

单位 R = Σ(持仓 × 价格变动 − 成本) / 当时的 ATR（按交易日汇总，纽约 17:00 为界）。回测（2020-01-01 起）日度 R 夏普 0.92，最大回撤 −64.3 R。

| 检查点（交易日） | 5% 分位（低于即**失败**） | 中位数 | 95% 分位 |
|---|---|---|---|
| 63 | −27.1 R | +12.8 R | +40.2 R |
| 126 | −25.9 R | +23.1 R | +61.2 R |
| 252 | −19.4 R | +39.9 R | +82.7 R |

- 失败：在 63 / 126 / 252 个交易日时，前向累计 R 低于对应的 5% 分位 → 停止策略并复查。
- 警告：低于中位数，或前向最大回撤超过回测最大回撤（−64.3 R）的 1.5 倍。
- 252 个交易日之前不对"有效"下结论；预期夏普以 0.41 为基准。
