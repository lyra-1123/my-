# 策略说明书：周度高低位突破（WK1H-v1）

> 通俗说法：金价冲到最近一周的最高价附近（或突破）就做多，跌到最近一周的最低价附近（或跌破）就做空；每天换日前平仓，第二天重新确认。
> 研究名称：XAUUSD 1 小时 · 周度（5 日）区间位置。因子名 `DailyRangePos5`。

> 状态：**候选（candidate）**，尚未登记模拟盘；是否登记、是否上 MT5 由用户决定。
> 行为指纹（2024 年全年的信号与目标仓位哈希）：`8906275556f2e757`，正式登记时写入 prereg.json。
> 代码：`paper/specs.py`（规格 WK1H-v1）、`factors/library/daily_state.py::factor_daily_range_pos5`、`factors/library/trend_continuation.py::daily_feature`、`factors/core.py`、`factors/evaluate.py`、`paper/engine.py`。
> 研究记录：`reports/batch15_prereg.md`（预登记）、`reports/batch15.md`、`reports/batch15_out.txt`、`reports/portfolio3/`（三策略组合回测）。

## 1. 一句话概括
当金价处在**最近 5 个交易日**价格区间的极端位置（相对最近约 1 个月的常态明显偏高或偏低）时，顺着这个方向持有；每天纽约 16:00 前平仓，19:00 起按同样规则重新判断。

## 2. 交易逻辑
- **周度高低点是短线交易者的参照**：上周的高点、低点是最常用的支撑阻力位，止损单和突破挂单堆在这些价位外侧。价格靠近或突破周区间边缘时，止损被触发、突破单跟进，推动价格继续朝同一方向走。
- **锚定效应的另一个时间尺度**：HA1H 用"一年高低点"做锚，WK1H 用"一周高低点"。锚点不同，触发时点就不同：两者日度相关只有 0.34。同一尺度上改用"5 日动量"写法（DailyMomentum5）在样本外失效，说明起作用的是"相对高低点的位置"，而不是单纯的收益延续（lessons L39）。
- **在组合中的位置**：TT30 看 30 分钟价格路径（数小时），WK1H 看一周，HA1H 看一年。WK1H 填补了中间的时间尺度。

## 3. 数据
- 与 TT30、HA1H 相同：Dukascopy M1（BID，UTC，含成交量），重采样为 1 小时 K 线（`[t, t+1h)` 左闭右开），丢弃未走完的 K 线，剔除成交量为 0 的 M1。
- 日线：由同一份数据按 **UTC 自然日** 重采样（与 HA1H 相同的 `htf_feature`），**只使用已收盘的日线**：某根日线在当天 24:00 UTC 之后才可用。
- 本策略**不使用成交量**，只用高、低、收。

## 4. 信号计算
参数（先验值，未调参）：区间天数 `5`，标准化窗口 `norm = 750`（1H 频率的先验值，约 31 个交易日）。

```
H5  = 最近 5 根已收盘日线的最高价的最大值
L5  = 最近 5 根已收盘日线的最低价的最小值
pos = 2 × (C − L5) / (H5 − L5) − 1        # C 为当前 1H 收盘价；区间底部 −1，顶部 +1，突破高点 > 1，跌破低点 < −1
z   = MAD_Z( clip(pos, −3, 3), 750 )       # 滚动 750 根 1H K 线去极值 + 标准化
```
- MAD_Z 与 TT30、HA1H 相同：滚动中位数 ± 3 × 1.4826 × MAD 截断，再做滚动均值、标准差标准化（最少 187 个样本；标准差为 0 时 z = 0）。
- 含义：z 衡量"价格在本周区间中的位置，相对最近一个月的常态有多极端"。z > 0 看多，z < 0 看空。
- 注意：H5、L5 在一个 UTC 日内不变（只在 UTC 0 点后更新），盘中变化的只有 C。所以当天价格冲出上周区间时，pos 会迅速超过 1。

## 5. 交易规则（与 TT30、HA1H 完全相同的统一执行规则）
- **执行时间窗（纽约时间，自动处理夏令时）**：1H 频率下，15:00、16:00、17:00 三根 K 线的 z 视为 0。
  - 效果：**16:00 开盘平掉所有仓位**，换日（17:00）时一定空仓，不付过夜费；**最早 19:00 开盘重新入场**。
- **迟滞开平仓**（每根 1H K 线收盘后判断）：

| 条件 | 空仓 | 持多 | 持空 |
|---|---|---|---|
| z > 1.5 | 开多 | 持有 | 反手做多 |
| 0.3 ≤ z ≤ 1.5 | — | 持有 | 持有 |
| \|z\| < 0.3 | — | 平仓 | 平仓 |
| −1.5 ≤ z ≤ −0.3 | — | 持有 | 持有 |
| z < −1.5 | 开空 | 反手做空 | 持有 |

- **成交**：第 t 根 1H 收盘出信号，第 t+1 根开盘市价成交；固定 **0.01 手（1 盎司）**；只有多 / 空 / 空仓三种状态，不加仓、不减仓。
- **没有止损、止盈、最长持仓时间**：出场只由信号消退、反手或 16:00 换日前平仓触发。

### 5.1 规则的实际效果
- **89% 的交易（1752 / 1969）由 16:00 换日前平仓结束**。由信号消退结束的 209 笔合计 −3342$，反手结束的 8 笔合计 −223$：信号消退往往意味着价格已经回到区间中部，这部分交易整体是亏的，盈利全部来自拿到收盘前的交易。
- **入场时间比 HA1H 分散**：纽约 19:00 入场占 32%（HA1H 约 2/3），其余大多在伦敦下午到纽约上午（09:00~12:00 占约 28%）。原因是盘中价格冲出周区间时 pos 会快速变化，而 HA1H 的一年区间一天之内几乎不变。
- **53.5% 的交易是"与前一交易日同方向的隔日重新入场"**。合并后共 915 个"持仓段"，平均 2.2 个交易日（中位 2 天，最长 15 天），段胜率 45%，段平均盈利 +19.6$、平均亏损 −11.7$。
- 在场时间约 22%（做多 10.8%、做空 11.6%），多空大体对称。

## 8. 风险与限制
1. **与 TT30 相关 0.49，贴近 0.5 的准入门槛**：当天价格冲出周区间时，TT30 的 30 分钟趋势信号往往也会触发，两者会同向叠仓。组合的单日风险因此比三个独立策略简单相加更集中。
2. **统计证据弱**：DSR 只有 0.23。前向预期应以 CSCV 中位数 0.72 为上限参考，并考虑选择偏差（第十五批 4 选 1），不宜按样本外 0.95 预期。
3. **依赖波动环境**：2018-2019 低波动年份连续亏损；美元利润集中在 2020 年后，尤其 2025-2026。
4. **信号消退出场的交易整体亏损**（209 笔 −3342$）：它是一个"要么拿到收盘、要么小亏出局"的结构，胜率约 50%，依赖少数大盈利日。
5. **日线按 UTC 自然日划分**：周区间在 UTC 0 点（纽约 19:00/20:00）更新，与经纪商服务器的日切不同；实时程序必须按 UTC 构造日线，不能直接用 MT5 的 D1 K 线。
6. **纽约 19:00 入场的点差风险**：32% 的入场在这个时点，与 HA1H 相同的执行风险（换日后第一个小时点差偏宽），需要用模拟盘实际点差复核。

## 9. 实时下单实现要求
与 TT30（`docs/strategy_TT30-EW-v1.md` 第 9 节）、HA1H（`docs/strategy_HA1H-v1.md` 第 9 节）相同，另外：
- 周区间 H5/L5 必须来自**已收盘的 UTC 日线**，与引擎的 `htf_feature` 逐根一致（UTC 0 点之后才能使用前一天的日线）；
- 预热：至少 5 根完整日线 + 750 根以上 1H K 线（MAD_Z），建议直接用全部历史重算；
- 每日 16:00 平仓、19:00 起重新判断是规则的正常结果，程序不要把它当成异常；
- 上线前按 TT30 的要求，在至少 3 个月的重叠历史上对账：实时程序算出的 z 与 `paper/engine.py` 相差 < 1e-6，目标仓位完全相同。
