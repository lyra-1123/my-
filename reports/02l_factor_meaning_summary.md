# 因子含义与参数汇总（窗口优化后的最终候选池）

对应 `scripts/02j_window_optimization.py`（窗口优化）+ `scripts/02k_optimized_validation.py`
（优化后重新验证）的最终结果。**两套窗口并存**：8个单因子用02k优化后的窗口；9对组合
沿用02i的原窗口（原因见 `reports/02k_optimized_validation_report.md`——单因子优化后的
窗口普遍更长/更少触发，AND组合直接套用会导致触发频率塌陷，两两组合的最优窗口需要
单独优化，这是下一步的工作，不是这次的范围）。

## 基础概念

- **模式=reversion**：`reversion_direction(factor, lo, hi)` —— 因子从自身历史20%分位
  以下**上穿**lo → +1(多头)；从自身历史80%分位以上**下穿**hi → -1(空头)。是一个穿越
  事件，不是静态阈值；lo/hi只在每折的训练区间上取分位数，冻结后用到测试区间（无未来
  函数）。这里全部19个变体测出来的最终候选清一色都是reversion模式——注意这是"因子
  自己从极值区间被拉回"的信号，不是"价格突破"信号，对波动率类因子(vol_of_vol/bb_width/
  parkinson_vol/garman_klass_vol/adx等)而言，经济解释是"波动率剧烈变化后开始回落/回升"，
  这是系统性扫描(02h)统计意义上找出来的规律，不是先验的经济假设。
- **pctrankN**：因子当前值在自身最近N根bar历史中的百分位排名(0~1)。因为金价这18年
  从~$860涨到~$5300+，同一个原始数值(比如ATR=$5)在不同年代含义完全不同，pctrank把
  它换算成"相对自己历史的位置"，解决这个问题。
- **持有期**：全部还是占位值12根M5(~1小时)，步骤3定真实持有期后需重新验证一次。

## 涉及的因子家族一览（去重，公式定义）

| 家族 | 公式(简化) | 一句话含义 | 所属大类 |
|---|---|---|---|
| `vol_of_vol` | `realized_vol(n).rolling(n).std()` | 波动率的波动率——衡量近期波动率本身有多不稳定 | 波动率 |
| `parkinson_vol` | `sqrt(mean(ln(high/low)²)/(4·ln2))` | 高低价区间波动率估计，比收盘价法更高效 | 波动率 |
| `bb_width` | `2k·std(close,n)/MA(close,n)` | 布林带宽度，相对价格归一化的波动率 | 波动率 |
| `garman_klass_vol` | 基于OHLC range+开收盘跳空方差 | 含隔夜跳空信息的OHLC波动率估计 | 波动率 |
| `adx` | Wilder DI+/DI-差值再平滑 | 趋势强度(不分方向)，越高越"顺畅地朝一个方向走" | 趋势强度 |
| `autocorr_returns` | 收益率与其滞后1期的滚动相关系数 | 正=动量(趋势延续)，负=均值回归 | 动量 |
| `avg_gap` | `mean(|open_t-close_{t-1}|/close_{t-1})` | 开盘跳空/不连续性的平均幅度，微观结构指标 | 价格行为 |
| `kurt_returns` | 收益率的滚动超额峰度 | 收益分布的尾部厚度(极端值多不多) | 价格行为 |
| `mean_reversion_speed` | AR(1)回归：`-cov(Δdev,dev_{t-1})/var(dev_{t-1})` | 价格偏离均线后被拉回的**速度**(不是距离) | 均值回归 |
| `realized_vol` | log收益率的滚动标准差 | 最基础的已实现波动率 | 波动率 |
| `roc` | `close.pct_change(n)` | n根bar的涨跌幅(变化率) | 动量 |
| `variance_ratio_2` | `var(2期收益率)/(2·var(1期收益率))` | Lo-MacKinlay方差比，>1趋势/<1均值回归 | 趋势强度 |
| `aroon_up` | `100·(n-距最近新高的bar数)/n` | 距离最近新高的"新鲜度"，越高越是刚创新高 | 动量 |
| `zscore_vs_ma` | `(close-MA(n))/std(n)` | 价格偏离均线的标准化距离(标准z-score) | 均值回归 |
| `stochastic_d` | `stochastic_k(n).rolling(3).mean()` | 平滑后的随机指标%K，价格在近期高低区间中的位置 | 均值回归 |
| `keltner_width` | `2·mult·ATR(n)/EMA(n)` | Keltner通道宽度，ATR版的"布林带宽度" | 波动率 |
