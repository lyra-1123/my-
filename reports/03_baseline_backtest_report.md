# 阶段3基线回测报告：无过滤器的马丁格尔网格

## 参数设定

| 参数 | 值 |
|---|---|
| 初始手数 | 0.01 |
| 加仓倍率 | 2.0x |
| 最大加仓层数 | 8 |
| 加仓间距 | 1.0 x ATR(14根H1) |
| 止盈距离(相对持仓均价) | 1.0 x ATR(14根H1) |
| 点差成本(每盎司，往返) | $0.3 |
| 隔夜利息(每手/天) | $-6.0 |
| 合约规模 | 100.0 盎司/标准手 |
| 杠杆 | 1:200 |
| 初始账户资金 | $10,000 |
| 强平保证金水平 | 20% |

**重要说明**：账户资金/杠杆/点差/隔夜利息是合理的占位假设，不是针对具体经纪商标定的，使用前应对照你的真实账户条件重新标定；但“有无regime过滤器”的相对比较对这些绝对数字的敏感度较低。方向固定为只做多（逢跌加仓，classic buy-the-dip martingale），这是本身的一个策略选择，不是从数据里学出来的——如果想测双向或只做空，需要单独跑。

## 结果（2009-2026全历史，无任何regime过滤器）

| 指标 | 数值 |
|---|---|
| 期末权益 | $-2,786 |
| 总收益率 | -127.9% |
| 最大回撤 | -102.7% |
| 止盈平仓次数 | 1,693 |
| 强平(爆仓)次数 | 1 |
| 历史最大加仓层数 | 8 |
| 账户是否破产 | 是，2013-04-15 14:00:00+00:00 |

**破产说明**：权益一旦跌破0，视为账户被券商强制关停，此后不再模拟任何交易（真实券商也会这样处理，不会让一个负权益账户继续用固定手数开新仓）。上面“强平次数”“止盈次数”只统计破产前的真实交易。

## 强平事件明细

| 时间 | 加仓层数 | 该次损失 | 强平后权益 |
|---|---|---|---|
| 2013-04-15 14:00:00+00:00 | 8 | $-105,418 | $-2,786 |

**不是单个bar的意外，是长达数月的失血后被最后一击补刀**：权益峰值$104,961出现在2012-10-09 03:00:00+00:00，此后一路下滑，到强平发生前（2013-04-15 14:00:00+00:00）已经跌到约$4,787（较峰值回撤95%），此时账户早已深陷不可逆的回撤，最后那一根H1 bar的暴跌只是压垮骆驼的最后一根稻草，不是唯一原因。这个时间点(2013年4月中旬)正是黄金史上最著名的暴跌之一——两天内跌去约$140-160，验证了引擎模拟出的这次破产不是数据或模型的bug，而是真实发生过的极端行情。
