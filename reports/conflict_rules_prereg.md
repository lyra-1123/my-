# 预登记：TT30 与 HA1H 方向冲突时的组合层仓位规则（2026-09-29）

> 在运行前提交，之后不修改。脚本：`research/conflict_rules.py`。两个策略的信号不变（冻结），只研究组合层"冲突时怎么处理"。
> 起因：用户观察到 HA1H 持空单浮亏一整天，而行情转向多头。单日表现是噪声，不作为证据；但"慢策略与快策略方向冲突"是一个此前没有检验过的组合规则。

## 假设
HA1H（日线级一年区间位置，慢）与 TT30（30 分钟趋势尾部，快）方向相反时，快信号代表更新的信息。让 HA1H 在冲突期间让位，能减少"扛单"的亏损。

## 规则（信号 t 收盘确定、t+1 开盘执行，无未来函数）
TT30 的目标仓位映射到 1H：1H K 线 [t, t+1h) 收盘时，取收盘于 t+1h 的那根 30MIN K 线的 TT30 目标仓位。
| 编号 | 规则 |
|---|---|
| C0 | 现状：两者独立 |
| C1 | 冲突时 HA1H 平仓（冲突结束且 HA1H 目标仍在，按目标恢复） |
| C2 | 冲突时 HA1H 跟随 TT30 反手 |
| C3 | 冲突时 TT30 平仓（慢信号优先，对照） |
| C4 | 冲突时两者都平仓 |

## 选择与判定
- 口径：两个策略日度 ATR·今 收益之和（点差 0.2$，同时报告 0.3$）。
- 选择：样本内（2009-2019）组合夏普最高者；只有样本内高于 C0 才算"改进"。
- 样本外（2020-2026.09）只跑一次。通过条件：样本外组合夏普 ≥ C0，且点差 0.3$ 时同样成立。
- 5 个试验登记进 rule_trials.csv。同时报告冲突频率、冲突期间 HA1H 的平均收益（检验"扛单"是否真的亏钱）。
