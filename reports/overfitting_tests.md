# 过拟合检验：CSCV / PBO / DSR（2026-09-27）

脚本：`research/overfitting_tests.py`；原始输出：`reports/overfitting_tests.txt`、`reports/overfitting_tests.json`。
收益：日度"ATR·今"口径（与价格水平无关），2009-2026，4608 个交易日。CSCV：16 块，12870 种切分。

## 结果

| 层面 | 策略数 N | 有效独立数 N_eff | PBO | 样本内最优在样本外的年化夏普（中位 [5%~95%]） | 样本外亏损概率 |
|---|---|---|---|---|---|
| A 参数层：趋势尾部 225 个参数配置 | 225 | 3.6 | **0.60** | +0.45 [+0.02 ~ +0.82] | 4.4% |
| B 研究层：因子库全部"因子 × 频率"（统一规则） | 81 | 16.1 | **0.03** | +0.45 [+0.06 ~ +0.74] | 3.4% |

所选策略（等权组合，chan=32 / 1.5 / 0.3）：年化夏普 0.78，偏度 +1.24，峰度 8.7。

| DSR 情形 | N | 运气能达到的夏普 SR0 | DSR |
|---|---|---|---|
| 只算参数层，N = N_eff(A) | 3.6 | 0.19 | 0.996 |
| 只算参数层，225 个全当独立 | 225 | 0.53 | 0.871 |
| 研究层，N = N_eff(B) | 16.1 | 0.64 | **0.731** |
| 全部研究（N_eff(A)+N_eff(B)+57 次登记试验） | 76.8 | 0.87 | 0.355 |
| 极端保守（全部当独立） | 363 | 1.05 | 0.118 |

PSR（与 0 比较，不做紧缩）= 0.9997。

## 解读

1. **参数层 PBO = 0.60 是"参数无所谓"，不是"策略无效"。** 225 个配置的有效独立数只有 3.6，它们几乎是同一个策略；在近似等价的配置里挑"样本内最好"，样本外排名接近随机，所以 PBO ≈ 0.5~0.6。但样本内最优在样本外仍然为正（亏损概率 4.4%）。结论与 walk-forward 一致：**不要调参，冻结先验参数**。
2. **研究层 PBO = 0.03：从因子库里"挑最好"的过程本身能推广。** 在 12870 种切分中，样本内最好的"因子 × 频率"在样本外几乎总是排在中位数以上。这是对"30MIN 趋势是事后挑出来的"这一担忧最直接的回应：在这个库里，挑选过程没有明显过拟合。
3. **DSR 取决于如何计算试验次数，结论是"中等证据"。** 按有效独立试验数（3.6 或 16.1）计算，DSR 为 0.996 或 0.73；如果把所有试验都当独立（明显高估，因为试验高度相关），DSR 降到 0.12~0.35。**在最合理的研究层口径（N_eff≈16）下，DSR 为 0.73，未达到 0.95 的显著性标准**：夏普 0.78 高于"16 次独立尝试中运气能得到的最高值 0.64"，但高得不够多。
4. **现实预期：** 两个层面的 CSCV 都给出"样本内最优在样本外的夏普中位数 ≈ 0.45"。这比全样本的 0.78 更接近未来的合理预期。

## 局限
- CSCV 假设收益平稳；本策略按真实美元明显依赖波动水平（L17），这里用 ATR·今 口径已消除大部分影响，但不是全部。
- 研究层 B 只包含统一规则下的策略；规则适配、择时、门槛等 57 次登记试验只进入了 DSR 的 N，没有进入 CSCV 矩阵。
- 有效试验数用特征值参与比估计，本身有误差。

## 结论
- 过拟合风险：**参数层可控（不调参即可），研究层 PBO 低**；但 DSR 在合理的 N 下只有 0.73，统计证据是"中等"，不是"确定"。
- 这不改变下一步：前向测试是唯一不受任何选择偏差影响的检验。建议前向评估以样本外夏普中位数 0.45 作为预期基准，而不是 0.78。
