# 预登记：TT30 + HA1H 的仓位管理规则枚举（2026-09-29）

> 在运行前提交，之后不修改。脚本：`research/position_sizing.py`；结果：`reports/position_sizing.md`。
> 仓位管理属于执行层，不改变 TT30-EW-v1、HA1H-v1 的信号和行为指纹；本研究不修改 live/ 和 paper/specs.py，是否在 MT5 上采用由用户决定。

## 0. 约束与目标（用户给定）
- 账户：1 万美元（起始资金 10,000$；5,000$ 作为敏感性报告）。
- 风险上限：账户最大回撤 ≤ 20%。
- 目标：在回撤上限内收益最大。
- 说明：仓位只能同比例放大收益和回撤，不能提高风险调整收益。所以"收益最大"必须以"回撤不超过上限"为前提。

## 1. 数据与口径
- 用两个策略冻结规格的信号（`paper/specs.py`），按统一执行规则得到逐笔交易：入场/出场时间、方向、每盎司净盈亏、入场时的 ATR（该策略自身频率）。
- 成本按真实口径：点差 0.3$/开平（模拟盘首日实测）+ 过夜费（两个策略每天换日前平仓，基本为 0）。
- 最小交易单位 0.01 手 = 1 盎司，手数只能取整数盎司，至少 1 盎司。
- 两个策略共用一个账户，入场时按当时已实现的净值计算手数。两者每天纽约 16:00~16:30 都会平仓，所以每日收盘净值就是按市值计的净值。回撤按日度净值计算。

## 2. 枚举（5 类规则 × 8 档 = 40 个配置）
| 规则 | 每笔盎司数 | 档位 |
|---|---|---|
| R1 固定手数 | n | n ∈ {1, 2, 3, 5, 8, 10, 15, 20} |
| R2 按净值比例 | ⌊净值 / 10,000 × k⌋ | k ∈ {1, 2, 3, 5, 8, 10, 15, 20} |
| R3 按 ATR 定风险（波动率平价） | ⌊净值 × f / ATR入场⌋（1 个 ATR 的不利波动 = 净值的 f） | f ∈ {0.1%, 0.2%, 0.3%, 0.5%, 0.75%, 1%, 1.5%, 2%} |
| R4 = R3 + 回撤降仓 | 净值低于历史高点 90% 时手数减半 | 同 R3 |
| R5 = R3 + 单日止损 | 当日已实现亏损超过净值 2% 后，当天不再开新仓 | 同 R3 |

## 3. 选择（只用样本内 2009-2019，起始 10,000$）
- 在"样本内最大回撤 ≤ 13.3%"的配置中，选**样本内年化收益最高**的一个。
- 13.3% = 20% ÷ 1.5：前向回撤通常超过回测（TT30、HA1H 的前向警告线都是回测最大回撤的 1.5 倍），所以给 1.5 倍余量。

## 4. 样本外验证（2020-01 ~ 2026-09，重新从 10,000$ 起，只跑一次）
通过条件：
- V1 样本外最大回撤 ≤ 20%；
- V2 样本外年化收益 > 0；
- V3 选中规则在同类 8 档中不是孤峰：相邻档的样本内回撤单调，样本外回撤也不超过 20% × 1.5。

同时报告（不作判定）：盈利天数占比、最长连续亏损天数、单日最大亏损、每年收益；以及固定 1 盎司（现状）的对照。

## 5. 试验数
40 个配置，全部登记进 rule_trials.csv。
