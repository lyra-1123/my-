## 一、信号强弱决定仓位（TT30-EW-v1、HA1H-v1）

### 问题
在跑策略按迟滞规则开平仓，仓位固定 1 单位（0.01 手）。|z| 越大，后续收益是否越高？如果是，按信号强度分级加仓能否提高**风险调整后**收益（夏普与规模无关，所以不比较美元总额）？

### 数据与口径
- 仓位、信号、成本全部来自模拟盘引擎 `paper.engine.compute`（与实盘一致：t 收盘出信号、t+1 开盘成交、换日前平仓、历史真实 0.2$ 点差 + 过夜费）。
- 每笔交易的入场强度 s = 开仓信号那根 K 线的 |z|。收益 R = 每根净收益 / 上一根 ATR（引擎的 net_R），按交易日汇总。
- 样本内 < 2020-01-01 ≤ 样本外。

### 检验 1：信息（强度与每笔收益的关系）
- 按 s 分三档（事先固定）：[1.5, 2.0)、[2.0, 2.5)、≥2.5，报告各档样本内 / 样本外的每笔 R 均值、t 值、笔数。
- 报告 Spearman(s, 每笔 R)，样本内外分开。

### 检验 2：分级仓位（事先固定的 2 套规则）
- **S0（现行）**：固定 1 单位。
- **S1 入场定档**：开仓时按 s 定手数并持有到平仓：[1.5,2) → 1，[2,2.5) → 2，≥2.5 → 3（即 0.01 / 0.02 / 0.03 手，符合最小手数）。
- **S2 动态跟随**：持仓期间手数 = 当前 |z| 所在档（<2 → 1，[2,2.5) → 2，≥2.5 → 3），档位变化即加减仓，每次变动按变动手数付点差；方向和开平仍由迟滞规则决定。
- **随机对照**：把 S1 各笔的手数在交易之间随机打乱（1000 次），保持手数分布不变，得到夏普的零分布。

### 通过标准（全部满足才建议做 -v2）
1. 检验 1：样本内、样本外都满足"档位越高，每笔 R 越高"（至少最高档 > 最低档），且 Spearman 同号为正。
2. 检验 2：S1 或 S2 的日度夏普在样本内、样本外都高于 S0，且都高于随机对照的 95% 分位。
3. 最大回撤（按平均手数归一）不明显变差。

试验计数：2 个策略 × 2 套规则 = 4 次，登记进 `reports/rule_trials.csv`。

## 二、日内对冲因子（仅用 XAUUSD）

### 定义
单品种数据下，"对冲"指**与在跑组合负相关、自身期望为正**的日内策略：在跑策略（趋势尾部 / 年内高低位）亏损的时段它赚钱，从而降低组合波动。
跨品种对冲（XAUUSD vs XAGUSD 价差）需要白银数据，数据到位后另行预登记。

### 方法：先扫描已有因子库，不新增因子（不增加研究层 N）
- 用研究层矩阵（全部"因子 × 频率"在统一规则下的日度 ATR·今 收益，`research/overfitting_tests.matrix_B`），只取日内频率（5MIN~1H）。
- 对照组合 = TT30-EW-v1 + HA1H-v1 的日度 R 之和（与 `research/candidate_vs_live.py` 同口径）。
- **筛选标准（事先固定）**：与在跑组合的日度相关 样本内 < 0 且 样本外 < 0；自身夏普 样本内 > 0 且 样本外 > 0。
- 对通过筛选的因子：按模拟盘口径（真实历史成本）计算加入后组合夏普（全样本、2020 年后），以及"在跑组合亏损日"上它的平均收益。
- 通过标准：加入后组合夏普在全样本与 2020 年后都不下降，且在组合亏损日上的平均收益为正。
- 若没有因子通过，结论为"现有日内因子中没有有效的对冲成分"，不在本次新挖因子。
