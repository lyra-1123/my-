# 预登记：TT30 的信号能否用在 15MIN / 5MIN（2026-09-29）

> 运行前提交，之后不修改。脚本：`research/tt_finer_bars.py`。TT30-EW-v1 冻结不动；本研究只回答"换成更细的 K 线是否更好"。

## 背景
因子库里 5MIN/15MIN 版本用各自默认窗口（32~36 根），回看时间只有 3~8 小时，落在短期反转区，结果为 🔄（L1、L17）。还没检验过的是**同样回看 16 小时、只把 K 线换细**的版本：信息与 TT30 基本相同，入场、出场更及时，但交易次数和点差更多。

## 配置（与 TT30 同样的两个因子等权、迟滞 1.5/0.3、换日前平仓）
| 编号 | 频率 | chan / atr / norm（根） | 回看时间 |
|---|---|---|---|
| T30（基准 = TT30） | 30MIN | 32 / 32 / 1000 | 16 小时 |
| T15s | 15MIN | 64 / 64 / 2000 | 16 小时 |
| T05s | 5MIN | 192 / 192 / 6000 | 16 小时 |
| 参考 T15d、T05d | 默认窗口 | 32/32/1500、36/48/2000 | 8 / 3 小时（因子库已测，只作对照） |

## 口径与判定
- 美元（1 盎司，点差 0.2$ 与 0.3$）与日度夏普（美元口径，2009-2019 / 2020-2026.09）；另报告年均交易笔数、每笔毛利、与 TT30 的日度相关。
- 细 K 线版本要"更好"，必须同时满足：
  1. 样本内夏普（点差 0.3$）高于 T30；
  2. 样本外夏普（点差 0.3$）不低于 T30；
  3. 样本外多空两侧都为正。
- 满足时只作为 TT30-v2 的候选交给用户决定；不满足则维持 30MIN。4 条试验登记进 rule_trials.csv。
