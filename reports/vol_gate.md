# 波动率门槛检验（2026-09-27）

脚本：`research/vol_gate.py`（预登记）；原始输出：`reports/vol_gate.txt`；试验登记：`reports/rule_trials.csv`。
对象：30MIN 趋势尾部等权组合（chan=32 / 1.5 / 0.3，换日前平仓）。规则：ATR30 ≥ k×0.2$ 才允许开仓/反手。
分段：2009-2014 选 k → 2015-2019 验证（低波动期）→ 2020- 观察（高波动期）；对照：逐段按同比例随机屏蔽 50 次。

| 时段 | 无门槛 净利 / 夏普 | 门槛 k*=12.5 净利 / 夏普 | 随机屏蔽 净利中位数 [5%~95%] | 门槛优于随机的比例 |
|---|---|---|---|---|
| 选择 2009-2014 | +112$ / 0.28 | +196$ / 0.33 | +326$ [+142 ~ +558] | 0.18 |
| 验证 2015-2019 | +12$ / 0.07 | −12$ / 0.01 | −33$ [−155 ~ +77] | 0.58 |
| 观察 2020- | +2018$ / 0.77 | +1870$ / 0.71 | +1967$ [+1805 ~ +2232] | 0.18 |

## 结论：否定
- 选择期的 k 与收益呈锯齿形（k=10 差、12.5 好、15 差），k* 本身像噪声。
- 验证期与随机屏蔽无差别；高波动期略有损害。
- 低波动期的真实美元表现是"保本"而不是"亏损"，避开它并没有省下什么；按 ATR 衡量的边际在低波动期依然存在（2015-2019 ATR·今 夏普 0.74 → 加门槛后 0.23）。
- 意外发现：2009-2014 随机少交易 58% 反而改善了美元结果 → 那段时期的改善来自"少交易"本身（成本相对高），而不是"避开低波动"。
- 处理：不加波动率门槛；低波动期的风险交给仓位管理（例如按 ATR 或账户风险定仓），而不是停手。
