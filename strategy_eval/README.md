# strategy_eval：15min策略 ETF 实盘评估工具

用中证1000指数15min算信号，在512100 ETF的真实1分钟价格上评估成交效果，并把实盘成交和回测信号逐笔对账。

信号逻辑直接复用盯盘脚本 `monitor_15min_signal.py` 里的 `prepare_indicators` / `replay_and_check_latest`，不重新实现，保证评估和实盘推送用的是同一套判断。

## 准备

```
pip install pandas numpy openpyxl requests
```

- **信号引擎**：把实盘电脑上正在跑的 `monitor_15min_signal.py` 复制到本目录，或者每次用 `--engine 路径` 指定。**这个文件不入库**（仓库是公开的，`.gitignore` 已排除）。
- **数据**：放在仓库根目录的 `data/` 下（同样不入库）。
  - 指数15min：iFinD导出的 `000852-15min.xlsx`，或盯盘脚本的缓存 `ifind_cache/000852_SH_15min_cache.csv`
  - ETF 1分钟：iFinD导出的 `512100-1min.CSV`（GBK编码，份额折算会自动识别并复权）

## 1. 回测：ETF 真实成交价下的表现

```
python backtest_etf.py --index ../data/000852-15min.xlsx --etf ../data/512100-1min.CSV
```

输出按起始日期（默认2021-01-01 / 2022-08-01 / 2024-01-01）分组，每组对比几种情景：

| 情景 | 说明 |
|---|---|
| 指数价格成交(回测口径) | 原回测，按指数收盘价成交、无成本 |
| 底仓T+0, 万一, 0 / 0.5 / 1tick | 有底仓可当日回转；佣金万一；单边滑点0/0.5/1个tick(0.001元) |
| 底仓T+0, 万一, 0.5tick, 延迟5分钟 | 信号出来后5分钟才成交 |
| 纯T+1, 万一, 0.5tick | 没有底仓：当天买入的出场信号推迟到次日09:31卖 |

成交价口径：信号bar收盘后**下一分钟的开盘价**（延迟情景用第N分钟收盘价），不参与集合竞价。

`--out 明细.csv` 可以导出逐笔明细，`--starts` 可以改起始日期。

## 2. 对账：实盘成交 vs 回测信号

每次交易后在成交记录CSV里加一行（格式见 `fills_template.csv`）：

| 列 | 必填 | 说明 |
|---|---|---|
| 成交时间 | 是 | `2026-09-29 10:01:25` |
| 方向 | 是 | 买 / 卖 |
| 成交价 | 是 | 实际成交均价 |
| 数量 | 否 | 拆单成交时用来算加权均价 |
| 手续费 | 否 | 用来算实际费率 |
| 信号时ETF价 | 否 | 收到推送那一刻看到的ETF价格；没有ETF分钟数据时作为滑点基准 |

只记**策略仓位**的买卖，不要记底仓调整。同方向、10分钟内的多笔成交会合并成一张单。

```
python reconcile_fills.py --fills ../data/我的成交.csv --index ifind_cache/000852_SH_15min_cache.csv
python reconcile_fills.py --fills ../data/我的成交.csv --index ../data/000852-15min.xlsx --etf ../data/512100-1min.CSV --out 对账.xlsx
```

输出内容：

- **执行情况**：信号总数、已执行、漏执行（列出是哪些信号）、信号之外的成交
- **执行延迟**：信号bar收盘到首笔成交的交易分钟数（不算午休/隔夜，15:00的信号次日09:35成交算5分钟）
- **滑点**：相对"信号确认后下一分钟ETF开盘价"，单位tick和%，正数=吃亏，**包含延迟期间的价格变动**，并给出对应回测哪个情景的判断
- **逐笔收益分解**：指数口径 → ETF信号时刻价格（差额=ETF跟踪/折溢价）→ 实盘成交价（差额=延迟+滑点）→ 扣手续费
- 明细写入 `--out`（`.csv` 会另外生成 `_pairs.csv` 逐笔收益；`.xlsx` 两张表在一个文件里）

注意：指数数据要覆盖首笔成交前至少60个交易日，状态机才能回放到跟实盘一致的状态。盯盘脚本的缓存保留180天，够用。

## 判断标准

- 平均滑点 ≤ 0.5 tick：跟回测"底仓T+0, 万一, 0.5tick"情景一致，按该情景的年化预期
- 0.5 ~ 1 tick：预期要往下调到1tick情景
- \> 1 tick：先改下单方式（限价单、挂单），再谈策略本身
- 实盘单笔均值（扣费后）持续低于 0.12%：策略在ETF上的优势不足以覆盖成本，考虑降仓或暂停
